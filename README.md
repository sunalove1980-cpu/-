# 포켓펫 (Pocket Pet)

모바일에서 사용하는 다마고치형 건강 펫 웹앱입니다. 아기 펫 한 마리가 숲속 오두막 장면 속에서
스스로 숨 쉬고, 눈을 깜빡이고, 돌아다니고, 하품하거나 잠드는 등 **현재 상태에 따라 스스로
행동**합니다. 정해진 GIF를 반복 재생하는 것이 아니라, 에너지·기분·수분 상태와 무작위 행동
규칙에 따라 매번 다른 다음 행동을 스스로 결정합니다.

사용자가 하단의 건강기록 버튼을 누르면 그 행동이 펫의 상태와 경험치에 바로 반영되고, 펫은
해당 장소로 실제로 걸어가 먹이를 받아먹는 보상 연출과 함께 기뻐합니다.

> ⚠️ 로그인과 Supabase(서버/DB) 연동은 아직 없습니다. 이름·상태·경험치·오늘 기록·커스텀
> 건강기록 목록은 이 브라우저의 localStorage에만 저장됩니다 (다음 단계에서 서버 연동 예정).

## 주요 기능

- **숲속 오두막 장면**: 파란 하늘에 구름이 천천히 흐르고, 나비가 가끔 지나다니는 조용하고
  편안한 배경. 실제 시간에 맞춰 하늘/초원 색이 아침 → 낮 → 노을 → 저녁 → 밤으로 바뀝니다
  (저녁·밤엔 별이 뜨고 오두막 창문이 따뜻하게 빛납니다).
- **살아있는 듯한 펫**: 숨쉬기, 랜덤 간격의 눈 깜빡임, 하품, 기지개, 냄새 맡기, 몽상하기,
  깡충 뛰기 등 다양한 자율행동이 무작위 가중치로 이어집니다. 오래 방치하면 스탯 감소가
  점점 빨라지고, 많이 외로워지면 눈물 + 먹구름과 함께 시무룩해집니다. 앱을 꺼둔 사이 지난
  시간만큼 "그리워하던" 페널티도 한 번에 반영됩니다.
- **실제 이동 + 손가락 따라오기**: 펫은 방 안 좌표를 따라 실제로 걸어서 오두막·연못·산딸기
  덤불·모닥불 앞까지 이동합니다. 화면을 누른 채 드래그하면 펫이 손가락을 따라오고, 놓으면
  더 사랑스러운 반응(폴짝 돌기, 부비부비, 씰룩씰룩 등 무작위)을 보입니다.
- **탭 반응**: 펫을 톡 누르면 하던 행동을 멈추고 사용자 쪽을 바라본 뒤, 매번 다른 애정
  표현(하트 바운스/한 바퀴 돌기/부비부비/씰룩거리기)을 하고 기분 스탯이 올라갑니다.
- **내가 정하는 건강기록 (최대 20개)**: 기본 제공 5종(물 마시기·걷기·건강한 식사·마음
  돌보기·수면 기록) 외에, 하단 액션바의 "+"를 눌러 원하는 건강 습관을 직접 추가/삭제할 수
  있습니다. 기록하면 ① 관련 스탯이 바로 오르고 ② 경험치와 "건강 에너지" 게이지가 차오르며
  ③ 펫이 먹이(선택한 아이콘)를 받아먹고 "+XP"가 떠오르는 보상 연출과 함께 기뻐합니다.
  수면 기록은 하품 후 잠옷을 입고 기뻐할 뿐 실제로 잠들지는 않습니다 (진짜 잠은 밤 시간대
  자율행동으로만 일어납니다).
- **오늘의 진행 상황**: 레벨/경험치, 건강 에너지 게이지, 연속 실천일(스트릭), 오늘 기록한
  항목을 하단 패널에 간단히 보여줍니다.
- **시간 맞춤 잔소리**: 너무 늦은 밤(23시~5시)인데 아직 안 자고 있으면 "얼른 자자"는
  말풍선을, 오후 3시가 넘도록 오늘 건강기록이 하나도 없으면 "뭐라도 해보자"는 말풍선을
  펫이 직접 띄웁니다.
- **localStorage 저장**: 펫 이름·상태·경험치·오늘 기록·연속 실천일·마지막 접속 시간·커스텀
  건강기록 목록이 저장되어, 새로고침하거나 앱을 껐다 켜도 이어집니다.

## 구조

```
src/
├─ App.jsx            # PetRoomScreen만 렌더링하는 최상위 컴포넌트
├─ index.css           # 전역 리셋 스타일
└─ pet/
   ├─ PetRoomScreen.jsx    # 메인 화면 (장면 + 펫 + 상태바 + 진행 패널 + 액션바 + 드래그 조립)
   ├─ Room.jsx / .css      # 숲속 오두막 장면(하늘·구름·별·오두막·연못·덤불·모닥불), 시간대 테마
   ├─ Pet.jsx / .css       # SVG 펫 캐릭터, 포즈/표정/보상·축하 파티클/잠옷/먹구름 애니메이션
   ├─ StatHud.jsx / .css   # 에너지/수분/기분 미니 상태바
   ├─ ActionBar.jsx / .css     # 하단 건강기록 칩 목록 (기본 5종 + 커스텀, 최대 20개)
   ├─ ActionManager.jsx / .css # 건강기록 행동 추가/삭제 관리 모달
   ├─ ProgressPanel.jsx / .css # 레벨·건강 에너지·연속 실천일·오늘 기록
   ├─ actions.js           # 건강기록 정의(기본 5종의 이동 위치/스탯 보정/파티클) + 커스텀 저장
   ├─ nag.js                # 시간대/오늘 기록 상황에 맞춘 잔소리 말풍선 메시지 선택
   ├─ storage.js           # localStorage 저장/불러오기, 날짜/연속일 계산, 오프라인 방치 페널티
   ├─ usePetSimulation.js  # 핵심 시뮬레이션 루프 (스탯/이동/행동 전이/기록/드래그 팔로우)
   ├─ behaviors.js         # 다음 행동을 뽑는 가중치 랜덤 로직 (밤 시간대·방치 가중치 포함)
   ├─ expression.js         # 활동 상태 → 표정/포즈 매핑
   └─ constants.js          # 장소 좌표, 속도, 스탯 변화율, 밤 시간/시간대 판별 등 상수
```

## 로컬에서 실행하는 방법

**준비물**: [Node.js](https://nodejs.org) 18 버전 이상 (npm 포함)

```bash
npm install
npm run dev
```

터미널에 나오는 주소(예: `http://localhost:5173`)를 브라우저에서 열면 앱이 보입니다.
모바일 화면 크기로 보려면 브라우저 개발자 도구의 기기 툴바를 사용하세요.

### 프로덕션 빌드

```bash
npm run build     # dist/ 폴더에 배포용 정적 파일 생성
npm run preview   # 빌드 결과물을 로컬에서 미리보기
```
