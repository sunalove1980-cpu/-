# 포켓펫 (Pocket Pet)

모바일에서 사용하는 다마고치형 건강 펫 웹앱입니다. 아기 펫 한 마리가 아늑한 방 안에서
스스로 숨 쉬고, 눈을 깜빡이고, 돌아다니고, 하품하거나 잠드는 등 **현재 상태에 따라 스스로
행동**합니다. 정해진 GIF를 반복 재생하는 것이 아니라, 에너지·기분·수분 상태와 무작위 행동
규칙에 따라 매번 다른 다음 행동을 스스로 결정합니다.

사용자가 하단의 건강기록 버튼(물 마시기·걷기·건강한 식사·마음 돌보기·수면)을 누르면 그
행동이 펫의 상태와 경험치에 바로 반영되고, 펫은 해당 장소로 실제로 걸어가 축하 행동을
합니다.

> ⚠️ 로그인과 Supabase(서버/DB) 연동은 아직 없습니다. 이름·상태·경험치·오늘 기록은
> 이 브라우저의 localStorage에만 저장됩니다 (다음 단계에서 서버 연동 예정).

## 주요 기능

- **살아있는 듯한 펫**: 숨쉬기(가슴 움직임), 랜덤 간격의 눈 깜빡임, 하품, 기지개, 낮잠 등
  독립적인 애니메이션 레이어가 겹쳐서 동작합니다.
- **상태 기반 자율행동**: 에너지 / 수분 / 기분 3가지 스탯이 시간이 지나며 서서히 변하고,
  이 값과 무작위 가중치를 함께 고려해 다음 행동(가만히 있기, 두리번거리기, 돌아다니기,
  침대로 가서 잠자기, 물그릇으로 가서 물 마시기 등)을 매번 다시 뽑습니다. 실제로 잠드는
  행동은 밤 시간대(21시~7시)에 확률이 크게 높아집니다.
- **실제 이동**: 펫은 GIF처럼 제자리에서 도는 게 아니라, 방 안 좌표를 따라 실제로 걸어서
  침대·물그릇·식사 자리·마음 돌보기 방석 같은 사물 앞까지 이동한 뒤 그 자리에 맞는 행동을
  합니다.
- **탭 반응**: 펫을 누르면 하던 행동을 멈추고 사용자 쪽을 바라본 뒤, 하트를 띄우며 기뻐하는
  반응을 보이고 기분 스탯이 올라갑니다.
- **건강기록 5종**: 물 마시기 · 걷기 · 건강한 식사 · 마음 돌보기 · 수면 기록. 기록할 때마다
  ① 관련 스탯(수분/에너지/기분)이 바로 오르고 ② 경험치와 "건강 에너지" 게이지가 차오르며
  ③ 펫이 해당 장소로 걸어가 항목마다 다른 파티클(물방울/별/사과/반짝임/달)과 함께
  기뻐합니다. 수면 기록은 하품 후 잠옷을 입고 기뻐할 뿐, 실제로 잠들지는 않습니다(진짜
  잠은 밤 시간대 자율행동으로만 일어납니다).
- **오늘의 진행 상황**: 레벨/경험치, 건강 에너지 게이지, 연속 실천일(스트릭), 오늘 기록한
  항목 체크리스트를 하단 패널에 간단히 보여줍니다.
- **localStorage 저장**: 펫 이름·상태(에너지/수분/기분)·경험치·오늘 기록·연속 실천일·마지막
  접속 시간이 저장되어, 새로고침하거나 앱을 껐다 켜도 이어집니다.

## 구조

```
src/
├─ App.jsx            # PetRoomScreen만 렌더링하는 최상위 컴포넌트
├─ index.css           # 전역 리셋 스타일
└─ pet/
   ├─ PetRoomScreen.jsx    # 메인 화면 (방 + 펫 + 상태바 + 진행 패널 + 액션바 조립)
   ├─ Room.jsx / .css      # 방 배경, 창문, 조명, 침대, 물그릇, 식사 자리, 방석
   ├─ Pet.jsx / .css       # SVG 펫 캐릭터, 포즈/표정/축하 파티클/잠옷 CSS 애니메이션
   ├─ StatHud.jsx / .css   # 에너지/수분/기분 미니 상태바
   ├─ ActionBar.jsx / .css     # 하단 건강기록 버튼 5종
   ├─ ProgressPanel.jsx / .css # 레벨·건강 에너지·연속 실천일·오늘 체크리스트
   ├─ actions.js           # 건강기록 5종 설정 (이동 위치/스탯 보정/파티클)
   ├─ storage.js           # localStorage 저장/불러오기, 날짜/연속일 계산
   ├─ usePetSimulation.js  # 핵심 시뮬레이션 루프 (스탯 변화, 이동, 행동 전이, 기록 처리)
   ├─ behaviors.js         # 다음 행동을 뽑는 가중치 랜덤 로직 (밤 시간대 가중치 포함)
   ├─ expression.js         # 활동 상태 → 표정/포즈 매핑
   └─ constants.js          # 방 좌표, 속도, 스탯 변화율, 밤 시간 판별 등 상수
```

## 로컬에서 실행하는 방법

**준비물**: [Node.js](https://nodejs.org) 18 버전 이상 (npm 포함)

```bash
npm install
npm run dev
```

터미널에 나오는 주소(예: `http://localhost:5173`)를 브라우저에서 열면 앱이 보입니다.
모바일 화면 크기로 보려면 브라우저 개발자 도구의 기기 툴바를 사용하세요.

### 프로덕션 빌드

```bash
npm run build     # dist/ 폴더에 배포용 정적 파일 생성
npm run preview   # 빌드 결과물을 로컬에서 미리보기
```
